Учебник по стилям: как устроен этот сайт

Раскладка вдохновлена лендингом Яндекс Практикума: крупные скругления, цветные акцентные блоки и объёмные иконки. Поверхности сделаны в стиле Liquid Glass — полупрозрачное «жидкое стекло» поверх мягких цветных пятен. Здесь разобран каждый приём — с живым примером и кодом, который можно взять себе.

01Дизайн-токены

Все цвета, радиусы и тени заданы один раз в CSS-переменных на :root. Компоненты используют только переменные, а не конкретные значения. Поэтому, чтобы поменять акцентный цвет на всём сайте, достаточно одной строки.

--bg
--tile
--glass
--text
--muted
--accent
:root {
  --bg: #eef0f6;                         /* основа под цветными пятнами */
  --tile: rgba(255, 255, 255, .55);      /* полупрозрачные плитки */
  --text: #1a1a1f;                       /* не чисто чёрный — мягче для глаз */
  --muted: #5c606b;                      /* второстепенный текст */
  --accent: #5b4cf0;
  --glass: rgba(255, 255, 255, .55);     /* заливка стекла */
  --glass-edge: rgba(255, 255, 255, .85);/* светлая кромка */
  --radius-xl: 32px;
}

.card .tile { background: var(--glass); border-radius: var(--radius-lg); }

02Тёмная тема

Благодаря токенам тёмная тема — это просто другой набор значений тех же переменных. Компоненты не меняются вообще. Нажмите на кнопку с солнцем или луной в шапке — образцы цветов выше перекрасятся.

  • Тема хранится в атрибуте data-theme на <html>.
  • При первом визите берётся системная настройка через prefers-color-scheme.
  • Выбор пользователя сохраняется в localStorage.
  • Скрипт подключён в <head> без defer: тема ставится до отрисовки, поэтому страница не «мигает» белым.
:root[data-theme="dark"] {
  --bg: #0b0b11;
  --glass: rgba(255, 255, 255, .06);   /* дымчатое стекло */
  --glass-edge: rgba(255, 255, 255, .14);
  --text: #ececf0;
  --accent: #8f83ff;   /* в тёмной теме акцент светлее, чтобы читался */
  color-scheme: dark;  /* тёмные скроллбары и поля ввода */
}

// theme.js
var saved = localStorage.getItem('theme');
var system = matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
document.documentElement.dataset.theme = saved || system;

03Типографика

Крупные заголовки набраны тонким начертанием (400), а важная часть фразы выделена жирным. Это приём Практикума: заголовок выглядит легко, но акцент считывается сразу. Размер задан через clamp() — он плавно растёт с шириной экрана без медиазапросов.

Показываю, что умею: каждая технология — с примером

h1 {
  font-weight: 400;
  font-size: clamp(32px, 5vw, 56px);  /* минимум, «резиновое» значение, максимум */
  line-height: 1.12;                   /* крупному тексту нужен плотный интерлиньяж */
  letter-spacing: -.02em;              /* и чуть сжатый трекинг */
}
h1 b { font-weight: 600; }

Шрифт — Onest из Google Fonts: бесплатный, создан с хорошей поддержкой кириллицы.

04Скругления и блоки

Страница собрана из крупных скруглённых блоков: первый экран, плитки, тёмный блок контактов. Радиус зависит от размера: чем больше блок, тем больше скругление. На телефоне радиусы уменьшаются, иначе углы «съедают» содержимое.

.hero  { border-radius: var(--radius-xl); }  /* 32px — большие секции */
.tile  { border-radius: var(--radius-lg); }  /* 24px — плитки */
.pill  { border-radius: 999px; }             /* «пилюля»: всегда полукруглые края */

@media (max-width: 640px) {
  .hero { border-radius: var(--radius-lg); }
}

05Градиент первого экрана

Мягкий «живой» фон — это несколько градиентов друг на друге. Внизу базовый линейный градиент, сверху два радиальных пятна, которые растворяются в transparent. Так получается эффект подсветки без картинок.

.hero {
  background:
    radial-gradient(60% 80% at 15% 20%, #8f7dff 0%, transparent 60%),  /* пятно слева вверху */
    radial-gradient(50% 70% at 90% 80%, #e05cf5 0%, transparent 60%),  /* пятно справа внизу */
    linear-gradient(135deg, #4b3ee0, #7b4cf0 55%, #b14cf0);            /* основа */
}

Слои перечисляются через запятую, и первый лежит сверху.

06Жидкое стекло (Liquid Glass)

Стекло видно, только когда за ним что-то есть. Поэтому под всем сайтом лежит зафиксированный слой с мягкими цветными пятнами, а плитки, шапка, кнопки и оглавление — полупрозрачные панели поверх него. Сама панель собирается из четырёх слоёв:

1. Полупрозрачная заливка
2. Светлая кромка
3. Блик и отсвет
4. Мягкая тень
body::before {                         /* цветные пятна под всем сайтом */
  content: ""; position: fixed; inset: 0; z-index: -1; pointer-events: none;
  background:
    radial-gradient(38% 46% at 6% 10%, var(--glow-1), transparent 70%),
    radial-gradient(34% 42% at 94% 16%, var(--glow-2), transparent 70%),
    radial-gradient(42% 50% at 88% 90%, var(--glow-3), transparent 70%);
}

.glass {
  background:
    linear-gradient(160deg, rgba(255, 255, 255, .6), transparent 45%),  /* 3: блик сверху-слева */
    var(--glass);                                                       /* 1: заливка */
  border: 1px solid var(--glass-edge);                                  /* 2: кромка */
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, .95),    /* 3: тонкий отсвет по верхнему краю */
    0 14px 34px -16px rgba(52, 38, 120, .3);   /* 4: тень с оттенком фона, а не чёрная */
}
  • Размытие backdrop-filter — только там, где под стеклом движется контент: в шапке и на кнопках поверх картинок. Пятна фона и так размытые, а размытие на каждой плитке заметно нагружает видеокарту.
  • Светлая тема — молочное стекло с тёмным текстом. Тёмная — дымчатое стекло, у кнопок снизу цветное свечение: inset 0 -10px 18px -10px цвета акцента.
  • Контраст проверяется по итоговому цвету — заливка плюс то, что под ней. Поэтому второстепенный текст здесь чуть темнее, чем на белом фоне.
  • Если в системе включено «Уменьшить прозрачность», медиазапрос prefers-reduced-transparency делает стекло обычными плотными панелями.

07Кнопки-пилюли

Основные действия — «капли» стекла с полностью круглыми краями: светлый отсвет сверху, лёгкое цветное свечение снизу и мягкая тень. При наведении кнопка приподнимается на 1px, а тень растёт: это даёт ощущение физической кнопки.

Обычная Прозрачная (ghost) Как «Резюме» в шапке 
.pill {
  padding: 12px 22px;
  border-radius: 999px;
  background: linear-gradient(180deg, rgba(255, 255, 255, .95), rgba(255, 255, 255, .7));
  border: 1px solid rgba(255, 255, 255, .9);
  box-shadow:
    inset 0 1px 0 #fff,                              /* отсвет по верхнему краю */
    inset 0 -3px 8px -2px rgba(120, 105, 230, .22),  /* свечение снизу, как в толстом стекле */
    0 8px 20px -10px rgba(40, 30, 110, .45);
  backdrop-filter: blur(10px) saturate(160%);
  transition: transform .15s, box-shadow .15s;
}
.pill:hover { transform: translateY(-1px); }

08Сегментированный переключатель

Стеклянная дорожка, внутри кнопки; активная — более плотная «капля» стекла с цветной тенью, будто приподнята. Состояние хранится в aria-selected: этот атрибут нужен экранным читалкам, и он же служит селектором для стилей.

.tabs { display: flex; padding: 5px; gap: 4px; border-radius: 999px; }   /* + рецепт стекла */
.tabs button[aria-selected="true"] {
  background: var(--glass-strong);
  border-color: var(--glass-edge);
  box-shadow: var(--glass-rim), 0 6px 14px -6px rgba(91, 76, 240, .45);
}

tabs.forEach(tab => tab.addEventListener('click', () => {
  tabs.forEach(t => t.setAttribute('aria-selected', t === tab));
  // ...и скрываем карточки чужой категории через атрибут hidden
}));

09Объёмные иконки на CSS

У Практикума иконки — 3D-рендеры. Здесь тот же эффект собран одними тенями, без картинок. По шагам:

.icon {
  border-radius: 30%;  /* «скруглённый квадрат», как у иконок приложений */
  background: linear-gradient(160deg, #5aa7f2, #2f7fd4 55%, #1d5fae);  /* 1: свет сверху-слева */
  box-shadow:
    inset 0 -10px 18px rgba(0, 0, 0, .22),        /* 2: затемнение снизу */
    inset 0 10px 18px rgba(255, 255, 255, .35),   /*    подсветка сверху */
    0 18px 30px -10px var(--glow);                /* 3: тень цвета самой иконки */
}
.icon::before {                                   /* 4: размытый блик */
  content: ""; position: absolute; top: 8%; left: 14%;
  width: 46%; height: 26%; border-radius: 50%;
  background: rgba(255, 255, 255, .35); filter: blur(4px);
}

Цвет тени задан переменной --glow на каждой иконке, поэтому синяя иконка отбрасывает синюю тень, а фиолетовая — фиолетовую.

10Адаптивная сетка

Карточки раскладываются одной строкой CSS — без медиазапросов. Браузер сам решает, сколько колонок шириной от 260px поместится, и растягивает их на всю ширину. Измените ширину окна, чтобы увидеть, как перестраивается пример.

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 20px;
}

11Плавающая стеклянная шапка

Шапка — стеклянная капсула с отступом от краёв: логотип слева, ссылки и кнопки справа, текущий раздел подсвечен «каплей». Она прилипает к верху при прокрутке, а контент под ней размывается.

Шапка поверх контента
.site-header { position: sticky; top: 0; z-index: 20; padding-top: 10px; }
.site-header .wrap {
  height: 56px; border-radius: 999px;
  background: var(--header-bg);                   /* полупрозрачный фон */
  backdrop-filter: blur(18px) saturate(170%);     /* размытие того, что под шапкой */
  border: 1px solid var(--glass-edge);
  box-shadow: var(--glass-rim), var(--glass-shadow);
}

position: sticky лучше, чем fixed: шапка остаётся в потоке документа, и под неё не нужно делать отступ.

12Подвал

Подвал повторяет структуру Практикума:

  • Верхняя строка: логотип слева, стеклянные кнопки-пилюли соцсетей справа.
  • Колонки ссылок: маленький серый заголовок, под ним список. Колонки строятся той же сеткой auto-fit.
  • Промоблок: стеклянная скруглённая плашка с призывом к действию.
  • Нижняя строка: крупный контакт слева, мелкий служебный текст справа.
.footer-cols {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 32px;
}
.footer-cols .footer-h { font-size: 13px; font-weight: 400; color: var(--muted); }

Учебник по стилям: как устроен этот сайт

Стиль вдохновлён лендингом Яндекс Практикума: светлая основа, крупные скругления, цветные акцентные блоки и объёмные иконки. Здесь разобран каждый приём — с живым примером и кодом, который можно взять себе.

01Дизайн-токены

Все цвета, радиусы и тени заданы один раз в CSS-переменных на :root. Компоненты используют только переменные, а не конкретные значения. Поэтому, чтобы поменять акцентный цвет на всём сайте, достаточно одной строки.

--bg
--tile
--text
--muted
--accent
:root {
  --bg: #ffffff;
  --tile: #f2f3f5;      /* фон плиток и серых блоков */
  --text: #1a1a1f;      /* не чисто чёрный — мягче для глаз */
  --muted: #6b6f7a;     /* второстепенный текст */
  --accent: #5b4cf0;
  --radius-xl: 32px;
}

.card .tile { background: var(--tile); border-radius: var(--radius-lg); }

02Тёмная тема

Благодаря токенам тёмная тема — это просто другой набор значений тех же переменных. Компоненты не меняются вообще. Нажмите на кнопку с солнцем или луной в шапке — образцы цветов выше перекрасятся.

  • Тема хранится в атрибуте data-theme на <html>.
  • При первом визите берётся системная настройка через prefers-color-scheme.
  • Выбор пользователя сохраняется в localStorage.
  • Скрипт подключён в <head> без defer: тема ставится до отрисовки, поэтому страница не «мигает» белым.
:root[data-theme="dark"] {
  --bg: #121214;
  --tile: #1e1f23;
  --text: #ececf0;
  --accent: #8f83ff;   /* в тёмной теме акцент светлее, чтобы читался */
  color-scheme: dark;  /* тёмные скроллбары и поля ввода */
}

// theme.js
var saved = localStorage.getItem('theme');
var system = matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
document.documentElement.dataset.theme = saved || system;

03Типографика

Крупные заголовки набраны тонким начертанием (400), а важная часть фразы выделена жирным. Это приём Практикума: заголовок выглядит легко, но акцент считывается сразу. Размер задан через clamp() — он плавно растёт с шириной экрана без медиазапросов.

Показываю, что умею: каждая технология — с примером

h1 {
  font-weight: 400;
  font-size: clamp(32px, 5vw, 56px);  /* минимум, «резиновое» значение, максимум */
  line-height: 1.12;                   /* крупному тексту нужен плотный интерлиньяж */
  letter-spacing: -.02em;              /* и чуть сжатый трекинг */
}
h1 b { font-weight: 600; }

Шрифт — Onest из Google Fonts: бесплатный, создан с хорошей поддержкой кириллицы.

04Скругления и блоки

Страница собрана из крупных скруглённых блоков: первый экран, плитки, тёмный блок контактов. Радиус зависит от размера: чем больше блок, тем больше скругление. На телефоне радиусы уменьшаются, иначе углы «съедают» содержимое.

.hero  { border-radius: var(--radius-xl); }  /* 32px — большие секции */
.tile  { border-radius: var(--radius-lg); }  /* 24px — плитки */
.pill  { border-radius: 999px; }             /* «пилюля»: всегда полукруглые края */

@media (max-width: 640px) {
  .hero { border-radius: var(--radius-lg); }
}

05Градиент первого экрана

Мягкий «живой» фон — это несколько градиентов друг на друге. Внизу базовый линейный градиент, сверху два радиальных пятна, которые растворяются в transparent. Так получается эффект подсветки без картинок.

.hero {
  background:
    radial-gradient(60% 80% at 15% 20%, #8f7dff 0%, transparent 60%),  /* пятно слева вверху */
    radial-gradient(50% 70% at 90% 80%, #e05cf5 0%, transparent 60%),  /* пятно справа внизу */
    linear-gradient(135deg, #4b3ee0, #7b4cf0 55%, #b14cf0);            /* основа */
}

Слои перечисляются через запятую, и первый лежит сверху.

06Кнопки-пилюли

Основные действия — белые кнопки с полностью круглыми краями. При наведении кнопка приподнимается на 1px и получает тень: это даёт ощущение физической кнопки.

Обычная Серая (ghost) В рамке, как в шапке 
.pill {
  padding: 12px 22px;
  border-radius: 999px;
  transition: transform .15s, box-shadow .15s;
}
.pill:hover {
  transform: translateY(-1px);
  box-shadow: 0 6px 18px rgba(20, 20, 40, .12);
}

07Сегментированный переключатель

Серая «капсула», внутри кнопки; активная — белая с тенью, будто приподнята. Состояние хранится в aria-selected: этот атрибут нужен экранным читалкам, и он же служит селектором для стилей.

.tabs { display: flex; padding: 4px; gap: 4px; background: var(--tile); border-radius: 999px; }
.tabs button[aria-selected="true"] { background: var(--bg); box-shadow: 0 2px 8px rgba(20, 20, 40, .12); }

tabs.forEach(tab => tab.addEventListener('click', () => {
  tabs.forEach(t => t.setAttribute('aria-selected', t === tab));
  // ...и скрываем карточки чужой категории через атрибут hidden
}));

08Объёмные иконки на CSS

У Практикума иконки — 3D-рендеры. Здесь тот же эффект собран одними тенями, без картинок. По шагам:

TS
2. Внутренние тени
TS
3. Цветная тень
TS
4. Блик
.icon {
  border-radius: 30%;  /* «скруглённый квадрат», как у иконок приложений */
  background: linear-gradient(160deg, #5aa7f2, #2f7fd4 55%, #1d5fae);  /* 1: свет сверху-слева */
  box-shadow:
    inset 0 -10px 18px rgba(0, 0, 0, .22),        /* 2: затемнение снизу */
    inset 0 10px 18px rgba(255, 255, 255, .35),   /*    подсветка сверху */
    0 18px 30px -10px var(--glow);                /* 3: тень цвета самой иконки */
}
.icon::before {                                   /* 4: размытый блик */
  content: ""; position: absolute; top: 8%; left: 14%;
  width: 46%; height: 26%; border-radius: 50%;
  background: rgba(255, 255, 255, .35); filter: blur(4px);
}

Цвет тени задан переменной --glow на каждой иконке, поэтому синяя иконка отбрасывает синюю тень, а фиолетовая — фиолетовую.

09Адаптивная сетка

Карточки раскладываются одной строкой CSS — без медиазапросов. Браузер сам решает, сколько колонок шириной от 260px поместится, и растягивает их на всю ширину. Измените ширину окна, чтобы увидеть, как перестраивается пример.

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 20px;
}

10Липкая шапка с размытием

Шапка как у сервисов Яндекса: логотип слева, ссылки и кнопка в рамке справа. Она прилипает к верху при прокрутке, а фон под ней размывается, как матовое стекло.

Шапка поверх контента
.site-header {
  position: sticky; top: 0; z-index: 20;
  background: var(--header-bg);          /* полупрозрачный фон */
  backdrop-filter: saturate(180%) blur(12px);
  border-bottom: 1px solid var(--line);
}

position: sticky лучше, чем fixed: шапка остаётся в потоке документа, и под неё не нужно делать отступ.

11Подвал

Подвал повторяет структуру Практикума:

  • Верхняя строка: логотип слева, серые кнопки-пилюли соцсетей справа.
  • Колонки ссылок: маленький серый заголовок, под ним список. Колонки строятся той же сеткой auto-fit.
  • Промоблок: серая скруглённая плашка с призывом к действию.
  • Нижняя строка: крупный контакт слева, мелкий служебный текст справа.
.footer-cols {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 32px;
}
.footer-cols h4 { font-size: 13px; font-weight: 400; color: var(--muted); }

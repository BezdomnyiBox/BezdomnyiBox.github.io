Параллакс при прокруткеParallax scrolling

Слои сцены двигаются с разной скоростью: дальние — медленнее, ближние — быстрее. Получается глубина, как в окне поезда. Прокрутите страницу и посмотрите на горы.

Подходит: промо и сторителлинг, туризм, презентации продукта. Не злоупотребляйте: у части людей вызывает укачивание — уважайте «уменьшение движения».

transform: translateYrequestAnimationFrameanimation-timeline
ГлубинаПрокрутите страницу
Показать JS и CSS 
const layers = stage.querySelectorAll('[data-speed]');
function update() {
  const r = stage.getBoundingClientRect();
  const p = (innerHeight - r.top) / (innerHeight + r.height) - .5;   // от −0,5 до 0,5
  layers.forEach(l => { l.style.transform = `translateY(${p * l.dataset.speed}px)`; });
}
addEventListener('scroll', () => requestAnimationFrame(update), { passive: true });
/* Без JavaScript: анимация, привязанная к прокрутке (поддерживается не всеми браузерами) */
@supports (animation-timeline: view()) {
  .layer { animation: rise linear both; animation-timeline: view(); }
  @keyframes rise { from { transform: translateY(60px); } to { transform: translateY(-60px); } }
}

Новая версия стекла из iOS 26 и macOS: почти прозрачные элементы с сильными бликами по краю, будто линза поверх контента. В отличие от глассморфизма, размытия мало — стекло «преломляет», а не затуманивает. Активная вкладка перетекает между кнопками.

Подходит: плавающие панели навигации, плееры, элементы поверх фото и видео.

# BezdomnyiBox.github.io

Сайт: https://bezdomnyibox.github.io

Чистые HTML, CSS и JavaScript без сборки. Всё, что запушено в `main`, через минуту появляется на сайте (GitHub Pages).

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: технологии и примеры |
| `guides.html` | Страница «Гайды» — карточки строятся из `guides-data.js` |
| `guides-data.js` | **Список гайдов и полезных ссылок** — сюда добавлять новые |
| `projects/*.html` | Кейсы проектов: мини-CRM, AI-ассистент |
| `guides/*.html` | Учебники по технологиям |
| `design.html`, `design/*.html` | Раздел «Дизайн»: гайды, галерея стилей, переключатель стилей, витрина из Pinterest (`design/showcase.html`, данные пинов — `design/pins.js`) |
| `ai.html`, `ai/*.html` | Раздел «AI и LLM»: гайды по LLM API, вызову инструментов, безопасности, тестам и Symfony AI |
| `guide.html` | Учебник по стилям сайта |
| `404.html` | Страница «не найдено» (пути в ней абсолютные) |
| `layout.js` | Общие шапка и подвал для всех страниц |
| `styles.css` | Общие стили и цвета светлой и тёмной темы |
| `docs.css` | Вёрстка учебников: оглавление, уроки, подсветка кода |
| `theme.js` | Переключатель темы |
| `og/*.jpg` | Обложки для превью ссылок в Telegram, HH и соцсетях |
| `sitemap.xml`, `robots.txt` | Для поисковиков; `sitemap.xml` собирается скриптом |
| `tools/` | Генератор учебников, Open Graph-теги, обложки — см. [tools/README.md](tools/README.md) |

## Как добавить ссылку на гайд

Откройте `guides-data.js` и допишите объект в список `LINKS` (внешние материалы) или `OWN_GUIDES` (свои учебники):

```js
{
  title: 'Название',
  description: 'О чём материал',
  url: 'https://...',
  category: 'PHP',
  icon: 'php',
  color: 'php' // php | sf | react | ts | css | docker | sql | ml | git | link | ai
},
```

## Как добавить свой учебник

Большинство учебников собирает генератор из контента на Python — так все страницы выглядят одинаково, а код в примерах экранируется автоматически:

```bash
python -X utf8 tools/guides/gen.py
```

Как устроен контент и как добавить новый учебник — в [tools/README.md](tools/README.md).

## После добавления любой страницы

```bash
python -X utf8 tools/seo.py
```

Скрипт добавит на страницу теги для превью ссылок и внесёт её в `sitemap.xml`.

## Как посмотреть локально

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000. Открывать `index.html` двойным кликом не стоит: часть скриптов в таком режиме не загрузится.
